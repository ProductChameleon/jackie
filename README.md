# Jackie

The official project management tool for Cursor Boston Cohort 1.

**Live:** [jackie.cursorboston.com](https://jackie.cursorboston.com)

## What It Does

Two-tab app built for the cohort:

- **My Stuff** — personal progress tracker across all 6 weeks. Add tasks, set due dates, track completion.
- **Cohort** — live submission browser pulling real data from the cursor-boston GitHub repo. Filter, search, and sort by week.

## Stack

React, Vite, Vercel. No backend, no auth. Data from GitHub API, persistence via localStorage.

## Contributing

Jackie is open to contributions from Cursor Boston cohort members. See [CONTRIBUTING.md](./CONTRIBUTING.md) to get started.

Open issues are labeled — look for `good first issue` to find something approachable.

## Local Development

```bash
npm install
npm run dev
```

Runs at `http://localhost:5173`.
