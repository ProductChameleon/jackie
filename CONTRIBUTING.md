# Contributing to Jackie

Jackie is the official project management tool for Cursor Boston Cohort 1. It's open to contributions from anyone in the cohort.

## Getting Started

**Prerequisites:** Node 18+

**Run locally:**
```bash
git clone https://github.com/ProductChameleon/jackie
cd jackie
npm install
npm run dev
```

The app runs at `http://localhost:5173`.

## How to Contribute

1. Check the [open issues](https://github.com/ProductChameleon/jackie/issues) for something labeled `good first issue`
2. Comment on the issue so others know you're working on it
3. Fork the repo and create a branch: `git checkout -b your-feature-name`
4. Make your changes
5. Push and open a PR against `main`

## What We're Looking For

- Bug fixes
- UI improvements
- New features from the issues backlog
- Documentation improvements

## Code Style

- React/Vite stack
- Keep components in `src/components`
- No backend, no auth -- everything runs off the GitHub API and localStorage
